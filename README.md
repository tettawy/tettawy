### What I'm building

**[beedak](https://github.com/tettawy/beedak)** — an interactive Arabic (RTL) website, live at **[beedak.vercel.app](https://beedak.vercel.app)**

- Mouse-reactive code background with a zoom lens
- A CSS 3D lab: rotate and move an ESP32, an Arduino, a breadboard and a sensor, then program the ESP32 with simple commands
- No framework, no build step, works without JavaScript, respects reduced motion
